# Health summary

Обезличенная статическая медицинская сводка с адаптивными представлениями для мобильных устройств.

- Исходные медицинские документы в репозиторий не входят.
- Ссылки на локальный архив намеренно отключены.
- Страница не заменяет консультацию врача и не предназначена для самостоятельной постановки диагноза.

Для публикации через GitHub Pages используйте корень ветки `main`.
