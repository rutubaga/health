# Health

Обезличенные сводки для приёма врача.

- `index.html` — эндокринолог: динамика лабораторных показателей и полный ранее опубликованный реестр.
- `gastro.html` — гастроэнтеролог: хронология обследований ЖКТ, ЭГДС, колоноскопия, два заключения гистологии, серология целиакии, исследования кала и динамика анализов крови.

Гастроэнтерологические бланки сверены 14.11.2026. Кальпротектин в бланке KDL от 13.12.2023: 55,1 мкг/г; дата заключений гистологии: 11.01.2024. Сведения из записи приёма отмечены отдельно от первичных исследований.

Исходные документы, ФИО, даты рождения, номера заказов и локальные ссылки не включены. Страницы не устанавливают диагноз; архивные назначения не являются текущей схемой лечения.

GitHub Pages: корень ветки `main`.
