# Health / Endo

Обезличенная мобильная сводка лабораторных результатов для эндокринолога.

- Графики динамики щитовидной панели, витаминов, ферритина, гомоцистеина и глюкозотолерантного теста.
- Отдельный блок половых и надпочечниковых гормонов с единицами, референсами и датами.
- Полный реестр показателей за 2020–2026 годы с поиском и раскрывающейся историей.

- Исходные медицинские документы в репозиторий не входят.
- Ссылки на локальный архив намеренно отключены.
- Страница не заменяет консультацию врача и не предназначена для самостоятельной постановки диагноза.

Для публикации через GitHub Pages используйте корень ветки `main`.
